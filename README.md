  <p style="margin-top: 0;">
    The <strong style="color: #FF0080;">Play All Channel Videos</strong> has been missing for a long time and it has bothered everybody ever since. For the deep feelers that want to listen back to old music from channels that have been around for over 17 years and still are uploading this is a fine solution because you can start by filtering all the channel videos by oldest, scroll down to load more and just select a batch to listen to. The batch size is limited to 50 because we're limited to YouTube's URL input and we don't want to depend on API requests.
  </p>

  <p style="font-style: italic;">
    YouTube is updating to a new interface so this will get broken at some point, we will update as we move on. Saving playlists not possible since this would require API. This script is intentionally kept simple to extend its lifespan. Feel free to fork.
  </p>

  <p style="margin-bottom: 0; font-weight: bold;">
    Install on Greasemonkey or Tampermonkey browser extension. <br/>
    <a href="https://greasyfork.org/en/scripts/588519-youtube-play-all-oldest-channel-videos">YouTube Play All Oldest Channel Videos GreasyFork</a>
  </p>

  <p style="margin-bottom: 0; font-weight: bold; color: #7928CA;">
